# Skill dành cho Codex

Thư mục lưu các skill được tạo và điều chỉnh riêng cho Codex.

Mỗi skill nằm trong một thư mục riêng theo cấu trúc:

```text
Codex/<ten-skill>/SKILL.md
```

Các skill Claude hiện có vẫn nằm trong thư mục `skills/` ở gốc repo.

Thư mục này hiện chưa có skill. Lưu file lên GitHub không tự cài hoặc kích hoạt skill trong Codex; cần cấu hình hoặc yêu cầu Codex đọc skill khi sử dụng.
